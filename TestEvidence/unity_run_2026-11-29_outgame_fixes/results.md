# 아웃게임 버그 수정 검증 (2026-11-29)

브랜치 `feature/gameplay-port`, Unity 6000.3.9f1. 검토에서 찾은 버그 11개를 고친 뒤 다시 돌린 결과입니다.

| 검사 | 결과 |
|---|---|
| 에디트 모드 테스트 | 6 / 6 통과 (`editmode_results.xml`) |
| 플레이 모드 테스트 | 8 / 8 통과 (`playmode_results.xml`). 새로 `ChangingToAKeyInUseSwapsThem`, `DroppedPlayersReadKoreanReasons` |
| 두 프로세스 네트워크 점검 (`-dmprofile=host` / `-dmprofile=client`) | 2회 연속 양쪽 ALL PASSED, 예외 0. 새 검사: 방장이 메뉴처럼 방을 닫음(`host_closed_room`), 참가자가 "방장이 방을 닫았습니다"를 받음(`client_told_host_closed_room`) |

## 고친 것과 확인 방법

| # | 버그 | 고친 내용 | 확인 |
|---|---|---|---|
| 1 | 창 모드만 바꾸면 적용 안 됨 | 해상도를 안 골랐으면 지금 크기로 창 모드만 적용 | 코드 (창이 있는 실행으로는 확인 안 함) |
| 2 | 일시정지 중 잡기 유지 | 입력이 끊기는 순간(메뉴, 다른 창) 잡기를 한 번 놓음 | 코드 |
| 3 | 키 변경 중 클릭이 새 키가 됨, 중복 키 | 변경 중엔 설정 화면 클릭 막음, 왼쪽 클릭은 잡기만 받음, 이미 쓰는 키면 서로 바꿈 | 테스트(바꾸기), 클릭 막기는 코드 |
| 4 | 맵이 덜 지어졌는데 로딩 화면이 사라짐 | 이 PC의 맵이 준비될 때까지 로딩 화면 유지 | 코드, 기존 흐름 테스트 통과 |
| 5 | 라운드 재시작마다 마우스 잠금 풀림 | 로딩 화면만 마우스를 가져갔으면 끝난 뒤 다시 잠금 | 코드 |
| 6 | 동시 참가로 인원 초과 | 허용했지만 아직 안 들어온 사람도 인원에 셈 | 코드 (Netcode 소스로 순서 확인) |
| 7 | "방장이 방을 닫았습니다"가 안 감, Netcode 영어 문구 노출 | 알린 뒤 Netcode가 참가자를 내보낼 때까지 기다렸다 정리, 영어 문구는 한국어로 | 두 프로세스 점검, 단위 테스트 |
| 8 | 설정은 닫을 때만 저장 | 연 채로 씬이 바뀌거나 꺼져도 저장 | 코드 |
| 9 | 기본값이 창을 되돌리지 않음 | 모니터 크기·테두리 없는 전체 화면으로 | 코드 |
| 10 | `-dmclient` 대기 12초 | 명령줄 참가는 60초 | 코드 |
| 11 | 한 PC 두 실행본의 같은 닉네임 | `-dmprofile=이름`으로 설정 파일 분리, 방 안 같은 닉네임은 "(2)" 붙임 | 두 프로세스 점검에서 파일 두 개 생성 확인 |

## 확인하지 않은 것

- 사람이 직접 하는 플레이: 일시정지 중 잡기 놓기, 재시작 후 마우스 잠금, 키 변경 중 클릭, 창 모드 변경. 배치 모드 테스트는 마우스 잠금과 창을 다루지 못합니다.
- 실제로 두 사람이 같은 순간 참가하는 장면 (6번)
